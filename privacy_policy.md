# Privacy Policy — PDF Tools

**Effective date:** April 21, 2026
**App:** PDF Tools (`com.devcodeapps.pdftools`)
**Developer:** DevCodeApps
**Contact:** farr3ll@rocketmail.com

## Summary

PDF Tools is a fully offline Android application. We do not collect, transmit, store, or share any personal data. Everything you do in the app happens on your device.

## Data we collect

**None.**

PDF Tools does not:
- Collect any personal information
- Transmit data over the internet (the app has no network permission and makes no network requests)
- Use analytics, tracking, advertising, or crash-reporting services
- Store data on any server
- Share any data with third parties

## File access

When you select a PDF or image file inside PDF Tools, the app uses Android's Storage Access Framework to read only the file(s) you explicitly choose. The app:
- Does not request broad storage permissions
- Does not scan, index, or inventory files on your device
- Only reads files you pick through the system picker

Files you process (merged PDFs, compressed PDFs, extracted images, etc.) are written to the app's private storage and made available via the system share sheet or save dialog. The app does not upload, copy, or transmit these files anywhere.

## Permissions

PDF Tools declares no runtime permissions. It operates entirely through Android's scoped storage and the Storage Access Framework.

## Children's privacy

PDF Tools is suitable for all ages. We do not knowingly collect information from anyone, including children under 13.

If this policy is updated, the new version will be posted at the same URL with a revised effective date.
